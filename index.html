Czym jest Git?

Git to rozproszony system kontroli wersji stworzony w 2005 roku przez Linusa Torvaldsa. Pozwala śledzić zmiany w plikach, wracać do wcześniejszych wersji i pracować w zespole bez nadpisywania swoich zmian nawzajem.

Git to program na Twoim komputerze, a GitHub to serwis, który przechowuje repozytoria w internecie.

Pierwsze kroki

git config --global user.name "Twoje Imię"
git config --global user.email "ty@example.com"

git init                  # nowe repozytorium
git add .                 # dodaj zmiany
git commit -m "Pierwszy commit"
git branch -M main
git remote add origin https://github.com/user/repo.git
git push -u origin main

Najczęstsze komendy

KomendaCo robi
